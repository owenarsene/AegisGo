# PRIVACY

Privacy by design. Collect the minimum.

- Default: foreground location only, progressive permission, value explained first.
- Do not store continuous movement history in MVP.
- Public incidents use rounded / radius / intersection display. Reporter exact GPS is never public.
- Optional evidence, when added, is private to moderation by default. Raw and public media use different access.
- Retention policies (later): location, reports, media, logs, deleted accounts.
- User controls (later): export where applicable, delete account, notification/location/media permissions.
- No precise-location ad targeting. Business model must not reward fear.
