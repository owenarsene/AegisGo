# MODERATION

Moderation is core infrastructure, not a Phase 9 add-on. Phase 1 only stubs the UX and a client-side description guard.

## Later pipeline

Automated pre-screen: hate, harassment, doxxing, personal accusation, phone/address/ID/plate, graphic violence, spam, duplicates.

Queue actions: approve, edit public precision, blur media, reject, remove, restrict, ban, escalate. Every action is audited.

AI may assist classification, duplicate/PII/spam detection, summary, translation. AI must not declare someone a criminal, a place dangerous, or an event certainly true. Humans can override.

Community confirm/contradict are data points. Popularity is not truth. One contradiction does not delete. Repeated contradictions can lower confidence, pause notifications, and enter review.

Never prompt users to go to a scene, be first reporter on-site, or earn points by arriving.
